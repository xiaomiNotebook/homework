# 代码阅读与标注材料

代码注释本身写入 `src/maintained` 中本人负责的 Java 文件。本目录保存六个人的阅读和标注过程材料。

每个 `member-N/` 必须包含：

1. `01-scope-and-reading.md`：文件清单、模块职责、关键流程和疑问。
2. `02-function-class-map.md`：功能—包—类—方法映射。
3. `03-annotation-log.md`：逐文件注释位置、目的和真实统计。
4. `04-peer-review.md`：复核意见、修订结果、构建结果和 PR 链接。

标注 PR 只允许增加或改进注释与上述过程文档，不得改变程序行为。发现缺陷时创建 Issue，留到维护阶段处理。
