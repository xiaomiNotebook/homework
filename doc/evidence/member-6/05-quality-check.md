## 3. 代码质量

- 新增类均有类级注释，说明职责边界、前置条件、生命周期与异常路径；延续项目既有中文注释风格。
- 纯逻辑类无 Android 依赖，便于单测与后续复用。
- 所有数据库游标在 `finally` 中关闭；查询返回 null 时按空数据处理。
- 偏好读取与写入均做越界归一化，脏数据不会导致崩溃。
- 未使用 API 21 以上才有的接口；未引入 AndroidX。
- 统计页查询在后台线程，主线程只做渲染；页面销毁后丢弃结果。
