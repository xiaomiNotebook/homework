## 2. M09 便签使用数据可视化

### 2.1 功能介绍

新增独立的便签数据统计页面，帮助用户了解个人记录情况。

### 2.2 功能要求与实现对应

| docx 要求 | 实现方式 |
|---|---|
| 统计便签总数、累计字符数、近期新增数量和文件夹数量 | 四项汇总卡片；由 `NoteStatsCalculator.summarize` 计算，`NoteStatsRepository` 提供数据 |
| 绘制近 7 天、近 30 天新增便签趋势图 | `NoteStatsCalculator.buildTrend` 生成按天计数，`StatsBarChartView` 绘制柱状图 |
| 绘制便签文件夹分布图 | `NoteStatsCalculator.buildFolderDistribution` 生成分布，`StatsBarChartView` 绘制；超过 6 项合并为“其他” |
| 支持切换统计时间范围 | 页面顶部“近 7 天 / 近 30 天”按钮，切换后重新统计 |
| 统计数据来自实际便签数据库 | 通过 `Notes.CONTENT_NOTE_URI` 与 `Notes.CONTENT_DATA_URI` 查询 Provider，不使用任何演示数据 |

### 2.3 统计口径（与验收标准对应）

- 只统计普通便签：`note.type = TYPE_NOTE`。
- 排除回收站：`note.parent_id <> ID_TRASH_FOLER`（-3）。
- 累计字符数只统计文本正文（`data.mime_type = text_note`），通话记录不计入。
- 文件夹数量只统计用户可见文件夹（`id > 0`），不含根目录、临时目录、通话记录目录和回收站。
- “近期新增”按自然日计算：今天往前数 N 天（含今天）内创建的非回收站便签。

### 2.4 入口

便签列表页 → 菜单 → “使用统计”。入口约定见 `doc/README.md` 的「界面入口与资源命名约定」一节与本文档 03-detail.md 第 6 节。

## 3. M10 沉浸式专注阅读模式

### 3.1 功能介绍

新增独立只读阅读模式，减少编辑控件干扰，改善长文本阅读体验。

### 3.2 功能要求与实现对应

| docx 要求 | 实现方式 |
|---|---|
| 新增独立只读阅读模式，区别于普通编辑页面 | 独立 `NoteReadingActivity`，正文为不可编辑的 TextView |
| 隐藏无关编辑工具，避免误触修改 | 阅读页无编辑控件，仅有返回、阅读时长与三个显示偏好按钮 |
| 提供浅色、护眼、深色三种阅读主题 | `ReadingPrefs` 定义三套背景色/正文色，按钮循环切换 |
| 支持字号、行距调整 | 三档字号（16/19/22 sp）与三档行距（1.3/1.6/1.9 倍），按钮循环切换 |
| 根据正文长度估算阅读时间 | `ReadingPrefs.estimateReadingMinutes`：按 300 字/分钟向上取整，非空至少 1 分钟，空文本为 0 |
| 保存个人阅读偏好 | 写入独立的 `note_reading_preferences`（`ReadingPreferenceStore`） |
| 退出阅读模式后恢复正常编辑状态 | 返回按钮/返回键 `finish()`，回到原编辑页面，原始便签内容不被修改 |

### 3.3 入口

便签编辑页 → 菜单 → “阅读模式”。进入前会先保存当前编辑内容，保证阅读的是最新正文；阅读页只读，不回写数据库。

## 4. 验收标准对照

### M09

- 用已知数量的测试便签验证统计结果 → 单元测试覆盖汇总、趋势、分布；页面数据来自真实 Provider。
- 新增、删除、恢复便签后刷新统计页面，数据正确更新 → 统计页面在 `onResume` 重新读取，回到页面即刷新。
- 空数据库正常显示 → 汇总为 0，图表为空，状态行显示“暂无便签数据”。

### M10

- 长文本、短文本、空文本及不同主题均能正常展示 → 空文本显示“该便签暂无内容”；主题/字号/行距可组合切换。
- 调整阅读偏好不改变便签原始内容 → 阅读页只做只读查询，无写操作。
- 重启后保留设置 → 偏好保存在 SharedPreferences，读取时做越界归一化。
