# Maintained Source

本目录是小组唯一的工作代码树，初始内容复制自 `src/original/` 对应的官方基线。

工作顺序为：先按六人分工完成代码阅读与注释，再在同一份已标注代码上完成 M1—M6 维护任务。不要再次创建其他源码副本，也不要直接修改 `src/original/`。

构建时将本目录视为原项目根目录：

- `AndroidManifest.xml`：Android 清单文件。
- `res/`：资源文件。
- `src/net/micode/notes/`：Java 源码。
- `NOTICE`、`README`：上游说明和许可声明，必须保留。

代码注释的过程材料放在 `doc/annotations/member-N/`；维护任务的设计、测试、截图和 PR 证据放在 `doc/evidence/member-N/`。
